# Quarantined Term Exchange protocol v1

The former CEX-owned `term-exchange-protocol` v1 source was removed from the
build on 2026-07-12. It is retained only in Git history and must not be used as
a current protocol source.

The active dependency is the semver-pinned, vendored release of the
TRNM-owned `trnm-economy-protocol` under
`vendor/trnm-economy-protocol`. Update that release from the TRNM repository
only after its package version and contract tests pass.
